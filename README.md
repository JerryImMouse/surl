# surl

Just a simple CLI tool I made for fun to make HTTP requests and color their outputs :)

## Building / Installation
You will need to have `git` and `cargo` with `rustc` installed.

```bash
# Clone this repository
git clone https:://github.com/JerryImMouse/surl.git surl && cd surl

# You can either install this globally or just build it
# To install globally use:
cargo install --path .

# If you just want to build this use:
cargo build --release # omit `--release` for a debug build
```
